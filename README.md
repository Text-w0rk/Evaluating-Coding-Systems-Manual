# Evaluating Coding Systems — A Builder's Audit Manual

A print-friendly audit manual for reviewing vibecoded and human-written code — an 11-phase checklist, risk matrix, 30-item rapid audit, and a Ship/Fix/Rebuild framework. Content is AI-generated.

Its aim is narrow: close the gap between *feeling* that code is correct and *knowing* that it is. The manual works for any code, but leans into the failure modes that AI-generated code tends to introduce.

## What's inside

The manual (`Evaluating-Coding-Systems-Audit-Manual.pdf`, 31 pages) covers:

- **11-phase evaluation checklist** — comprehension, debugging readiness, error handling, security, architecture, testing, scaling, production viability, necessity, maintenance, and debugging the AI tools themselves. Each phase has an objective, what to check, questions to ask yourself, red flags, and pass criteria.
- **Risk matrix** — 14 categories of failure specific to AI-generated code, each with how to detect it and a severity rating.
- **Rapid audit** — a 30-item checklist for when you need to ship tomorrow.
- **Ship / Fix / Rebuild** — a decision framework for what to do once the audit is done.
- **Appendices** — a glossary, tooling by language, a fillable audit-report template, and questions to feed back to your AI.

The checkboxes and score boxes are meant to be filled in — print it, or keep it open beside your editor.

## AI disclosure

**This manual was written by an AI.** The text was generated by Claude (a model by Anthropic) from a detailed specification, and the PDF was produced with the same tool. I directed the structure and reviewed the result, but the bulk of the writing is model-generated.

Treat it as a useful starting checklist, not authoritative or exhaustive guidance. Verify anything you rely on for real decisions.

## Usage

Download `Evaluating-Coding-Systems-Audit-Manual.pdf` and open it in any PDF reader, or print it. No installation, no dependencies.
